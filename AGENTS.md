## Agent skills

### Humanizer evaluation

Use the [delivery milestones](ROADMAP.md#delivery-milestones) to plan revision work. Before building the full editor, compare Balik with the fixed basic copyedit on development drafts. Keep each author and every version of their draft on one side of the development/test split.

For a beta decision, apply the [blind comparison and beta criteria](ROADMAP.md#blind-comparison-and-beta-criteria) to each language and writing context separately. Report the counts behind each decision and keep reviewer and writer assessments blind to detector scores. Use the [provider reporting rules](ROADMAP.md#how-we-will-evaluate-the-3-target) when describing detector results.
